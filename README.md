## Sobre o Projeto
Aplicação web gratuita e responsiva em arquivo único (`index.html`), desenvolvida com HTML5, CSS3 e JavaScript puro para apoiar pequenos trabalhadores autônomos, comerciantes e moradores da comunidade local:

* **Vitrines Locais:** Cartões digitais com lista de serviços, valores, horário de atendimento, formas de pagamento e botão de contato direto via WhatsApp.
* **Guia Contra Golpes:** Recomendações práticas e visuais para prevenir fraudes no Pix e no WhatsApp (golpe do parente com número novo, comprovante de Pix falso, links suspeitos e ativação da confirmação em duas etapas).
* **Formulário de Avaliação:** Botão integrado para coleta de percepção e impacto com os participantes.

## Como Publicar no GitHub Pages
1. Adicione o arquivo `index.html` e atualize o `README.md` na branch `main` do repositório `Extensao-Anhguera`.
2. Acesse **Settings > Pages** no repositório.
3. Em **Build and deployment > Branch**, selecione **`main`** e a pasta **`/ (root)`**, e clique em **Save**.
4. Aguarde cerca de 1 minuto e acesse `https://ricardosantos02.github.io/Extensao-Anhguera/`.
